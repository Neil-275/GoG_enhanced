Tạo một folder lớn cho project, `cd` folder đó.
+ clone thành folder tên GoG:
```
git clone https://github.com/Neil-275/GoG_enhanced GoG
```
+ Load folder brink_dataset vào  
Cấu trúc folder:
```
folder
|- brink_dataset
|- GoG
```
+ Build environment  
+ Chạy:
```
python -m GoG_v2.GoG --dataset {dataset_path}
```
